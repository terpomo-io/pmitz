# Pmitz Logo

`pmitz-logo.png` is the canonical Pmitz product logo, exported from the complete
logo composition in `Pmitz_Deck.pptx`. It includes the cropped icon and wordmark,
the cover over the original small tagline, and the readable dark
"Subscriptions, Plans & Limits" text added on the slides.

Export the complete composition when updating it; extracting just the embedded
picture omits the slide's text and cover shapes.

Update the logo here. The GitHub README references this file, and the Terpomo
website copies it during its build. Use this same file in samples and
presentations; do not maintain separately edited copies in other repositories.
