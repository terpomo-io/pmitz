# Pmitz Logo

`pmitz-logo.png` is the canonical Pmitz product logo supplied by the product
owner. Its tagline is "Subscriptions | Entitlements | Monetization".
Only the surrounding empty canvas has been cropped; the artwork has not been
redrawn, resized, or recolored.

Update the logo here. The GitHub README references this file, and the Terpomo
website copies it during its build. Use this same file in samples and
presentations; do not maintain separately edited copies in other repositories.
